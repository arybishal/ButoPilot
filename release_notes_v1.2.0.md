# ButoPilot v1.2.0 - Automatic Proxy Generator

## New Features
- **Automatic Proxy Generator**: Added an Automatic Proxy Generator in VPN & Proxy Management (`ProxyListScreen`), accessible from both the action bar ("Auto Generate") and the top-right menu ("Automatic Proxy Generator").
- **Tier Selection**: Supports generating proxies by **Top Tier**, **Mid Tier**, and **Low Tier** quality and regional classifications.
- **Country Selection**: Multi-select country picker with search, quick presets (All, Top Tier, Mid Tier, Low Tier), and optional protocol filter (All, HTTP, HTTPS, SOCKS5).
- **Quantity Control (1 to 500)**: Slider, numeric input with validation, steppers, and quick presets (10, 50, 100, 250, 500) enforcing a minimum of 1 and maximum of 500 proxies per generation.
- **Multi-Source Fetching & Ranking**: Concurrent fetching from Proxifly and GeoNode proxy sources with deduplication, tier-based scoring, and optional automatic health testing after generation.
