# ButoPilot v1.2.7 - Suggested Domain Names for Target Websites

## New Features
- **Suggested Domains in Create Automation (`CreateAutomationScreen`)**: Automatically extracts unique domain names from previously saved automation profiles and displays them as one-tap **Suggested Domains** chips under the Target Website input.
- **Suggested Domains in Traffic Generator (`TrafficScreen`)**: Displays unique domain names from previous traffic runs as one-tap **Suggested Domains** chips under Website Target URL.
