# ButoPilot v1.1.4 — Clean Documentation & Markdown Standardization

We are pleased to release ButoPilot v1.1.4, standardizing all documentation, historical release notes, and GitHub release metadata to follow clean, professional text formatting without emojis.

---

### Key Updates

#### 1. Documentation & Metadata Standardization
- Standardized all repository markdown documentation (`README.md`, `RELEASE_NOTES_v1.0.0.md`, `release_notes_v1.1.0.md`, `release_notes_v1.1.1.md`, `release_notes_v1.1.2.md`, `release_notes_v1.1.3.md`, `AGENTS.md`) by stripping emoji glyphs across all headings, bullet items, and feature highlights.
- Updated all existing GitHub release descriptions (`v1.0.0`, `v1.1.0`, `v1.1.1`, `v1.1.2`, `v1.1.3`) via GitHub CLI to eliminate emojis in titles and release bodies.

#### 2. Workflow Guidelines Enforcement
- Codified strict policy in `AGENTS.md` prohibiting emojis in commit messages, release titles, release notes, PR bodies, and repository documentation.
