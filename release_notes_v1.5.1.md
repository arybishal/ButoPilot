# ButoPilot v1.5.1 - Live Scrolled, Clicked & Tasks Done Counters

## New Features
- **Activity Counters (`AutomationCoordinator`, `AutoHumanBehaviourScript`)**: Added `totalScrolls`, `totalClicks`, and `totalTasksDone` to `EngineState`, tracking scroll operations, click actions, and completed automation tasks.
- **Dashboard & Monitor UI (`HomeScreen`, `AutomationMonitorScreen`)**: Displayed **Scrolled**, **Clicked**, and **Tasks Done** directly below **Elapsed**, **Tabs**, **Actions**, and **Memory**.
