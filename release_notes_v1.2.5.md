# ButoPilot v1.2.5 - Clear HTTP 401/403 Diagnostics in Traffic Generator

## Improvements
- **Clearer HTTP 401/403 Status Messages (`TrafficExecutor`)**: Replaced raw `HTTP 401` / `HTTP 403` notes with descriptive messages (`HTTP 401: Target URL requires authentication/password protection` and `HTTP 403: Access forbidden by target server`) so users can immediately identify auth-protected or blocked target URLs.
