# ButoPilot v1.2.6 - Pop-up & Background Automatic Proxy Generator

## New Features
- **Background & Pop-up Proxy Generation (`AutomaticProxyGeneratorManager`)**: Added an application-scoped proxy generation manager so proxy generation and live health-checking can run in either the pop-up dialog or in the background while you run other automations.
- **Run in Background Option (`ProxyListScreen`)**: Added a "Run in background (continue while using app)" option before starting and a "Run in Background" minimize button during live checking, plus a live background progress banner with "Pop-up" and "Stop" controls.
- **Progressive Saving**: Healthy proxies are saved to the database as each batch completes so progress is preserved even if stopped early.
