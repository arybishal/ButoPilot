# ButoPilot v1.3.0 - Stealth, Human Behavior & Organic Search Traffic Mode

## New Features
- **Organic Search + Browser Mode (`TrafficMode.ORGANIC_SEARCH`)**: Added a new traffic mode simulating organic search engine discovery (Google, Bing, DuckDuckGo) with stealth WebView execution.
- **Stealth & Human-Like Behavior (`TrafficExecutor`)**: Added WebView stealth script injection (`navigator.webdriver`, `languages`, `hardwareConcurrency`, `deviceMemory`), third-party cookie support for analytics, smooth human-like scrolling, and randomized 2.5s-4.0s dwell time in `REAL_BROWSER` and `ORGANIC_SEARCH` modes.
- **UI Consistency (`TrafficScreen`)**: Integrated the new mode and feature badges seamlessly into the existing Traffic Generator card theme.
